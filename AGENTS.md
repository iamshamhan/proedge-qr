# Instructions for AI Coding Agents

1. Read `PROJECT_HISTORY.md` before starting work.
2. Inspect `git status --short --branch` and the existing implementation; preserve all uncommitted changes.
3. Keep changes scoped, preserve working functionality and existing URLs, and avoid unnecessary dependencies or architectural changes.
4. Test relevant behavior before declaring work complete. Never claim a test or build ran unless it actually did.
5. Update `PROJECT_HISTORY.md` at the end of every coding session with changes, decisions, tests, current status, pending work, known issues, and next-agent instructions.
6. Never commit or push unless the user explicitly requests it.
